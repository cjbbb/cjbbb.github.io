# Jianbin Cui — Resume site

A static, GitHub Pages-ready personal resume built with plain HTML, CSS, and JavaScript. It has no build step or runtime dependency.

## Files

- `index.html` — page structure and resume content
- `styles.css` — responsive visual system, dark mode, print styles, and reduced-motion support
- `script.js` — theme toggle, mobile navigation, scroll progress, reveal states, and copy-email feedback
- `CV_Cui,Jianbin.pdf` — downloadable resume source

## Deploy to GitHub Pages

1. Create a repository for the site and upload the files in this folder.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the default branch and the `/ (root)` folder, then save.

The site is intentionally self-contained so it can also be hosted on any static file host.
